# Data Engineering Labs

Laboratorios guiados de mi ruta de aprendizaje en ingeniería de datos: desde los fundamentos
(terminal, Git, Python profesional, Docker, SQL) hasta orquestación, transformaciones modernas,
procesamiento distribuido y streaming, con Google Cloud Platform como plataforma de nube.

Los proyectos completos de portafolio viven en repositorios independientes y se enlazan desde aquí.

## Estructura

| Módulo | Tema | Estado |
|---|---|---|
| 00 | Entorno profesional: terminal, Git, Python, Docker | En progreso |
| 01 | SQL a nivel ingeniería (PostgreSQL) | Pendiente |
| 02 | Python para datos: pandas, Polars, Parquet, APIs | Pendiente |
| 03 | Arquitectura de datos y modelado dimensional | Pendiente |
| 04 | Orquestación con Apache Airflow | Pendiente |

| 06 | GCP e infraestructura como código (Terraform) | Pendiente |
| 07 | Procesamiento distribuido con PySpark | Pendiente |
| 08 | Streaming con Kafka y Pub/Sub | Pendiente |
| 09 | Calidad, gobernanza y observabilidad | Pendiente |
| 10 | DataOps y diseño de sistemas de datos | Pendiente |

## Convenciones

- Los datos no se versionan: cada laboratorio incluye un script `download_data.sh` que los descarga.
- Commits siguiendo [Conventional Commits](https://www.conventionalcommits.org/).
- Cada laboratorio tiene su propio `notas.md` con hallazgos y decisiones.
